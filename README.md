# World Layoffs SQL Project

This project focuses on data cleaning and exploratory data analysis (EDA) using a global layoffs dataset in SQL.

## Key Steps & Workflow

* **Data Cleaning:** Removed duplicate records, standardized text and date formatting, handled missing/null values, and removed unnecessary columns or rows to ensure data integrity.
* **Exploratory Data Analysis (EDA):** Analyzed trends, patterns, and key metrics across industries, companies, and locations to extract actionable insights from the dataset.
